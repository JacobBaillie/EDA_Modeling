# Data Exploration & Modeling

---

## How to Use

**Setup** - Imports
**Load** (optional) - Aggregate CSV files
**Browse** - Inspect data
**EDA: Metrics** - Stats, correlations, describe
**EDA: Visualizations** - Distributions, scatter, heatmap
**Clean** - Outliers, filters, etc. **Creates df_clean**
**Encode and Regularize** - Refresh columns, one-hot encode. **Creates df_ready**
**Scale** (optional) - StandardScaler
**Regression** - Train, evaluate, results
**Classification** - Train, evaluate, results
